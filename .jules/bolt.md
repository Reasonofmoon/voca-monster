## 2024-04-06 - [React Hook Constraints in Memoized Components]
**Learning:** When refactoring a functional component to use React.memo and introducing new hooks (like useMemo) to optimize performance (such as caching regex and string split operations), the new hooks must be placed before any early returns (like `if (condition) return fallback;`). Violating this rule breaks React's Rules of Hooks. Also, when splitting strings using a capturing regex, odd-indexed parts in the resulting array are guaranteed to be matches, allowing O(N) lookup operations to be optimized to an O(1) parity check (`index % 2 === 1`).
**Action:** Always verify the structure of components for early returns before injecting React hooks during optimization, and leverage capturing regex index properties to achieve O(1) match checks in mapping functions over parsed strings.
