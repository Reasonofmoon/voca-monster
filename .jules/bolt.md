## 2025-06-19 - React.memo Component Typing and Capturing Group Split Regex Index Match
**Learning:** When using `React.memo` with a component that needs explicitly typed props without triggering TS type mismatch with `React.FC`, you should provide the generic type directly to the memo call, like `const Component = React.memo<Props>((...) => ...)`. Furthermore, using `String.prototype.split` with a capturing group in the regular expression guarantees that odd indices in the resulting array correspond exactly to the matches.
**Action:** When refactoring a functional component to use `React.memo` inside a TypeScript codebase, avoid assigning `React.FC<Props>` to the resulting `MemoExoticComponent`. When matching text iteratively using regex against a list of terms, use a capturing group in the split logic and check `index % 2 === 1` for O(1) matching instead of executing O(N) `.some()` checks for each array item.
