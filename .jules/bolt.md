## 2024-06-08 - Fast Exact String Lookup via Capturing Group Split
**Learning:** In `App.tsx` (`AnalyzedContent`), the component highlighted words by splitting a large text using a Regular Expression with a capturing group `(...)`. When Javascript's `String.prototype.split()` is used with a capturing group, the matched groups are inserted directly into the resulting array at exactly the odd indices (1, 3, 5...). The previous code used an O(N * M) nested loop (`array.some(...)`) inside the map function to detect which strings were highlights. Because of this native JS behavior, this can safely and elegantly be reduced to an O(1) mathematical lookup (`index % 2 === 1`).
**Action:** When optimizing string matching and highlighting logic that uses `split` with capturing regexes, skip nested string searches and utilize the odd-index trick (`index % 2 === 1`) to achieve O(1) identification.
