## 2024-06-27 - O(1) Text Highlighting in React with Regex Split
**Learning:** When using `String.prototype.split` with a regex capturing group to extract matches from text (e.g., for highlighting), JavaScript guarantees that the matches will be placed at the odd indices of the resulting array. This transforms an expensive O(N) array search (`words.some(...)`) during iteration into an O(1) mathematical check (`index % 2 === 1`). Furthermore, hooks like `React.useMemo` must always be placed *before* any early returns to avoid violating the Rules of Hooks.
**Action:** When implementing text highlighters or formatters using regex split, use the index parity property instead of iterating over match arrays for O(1) performance. Always place memoization hooks at the very top of components.
