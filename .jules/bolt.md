## 2025-05-26 - [AnalyzedContent O(1) Text Highlighting & Memoization]
**Learning:** In text highlighting components using `String.prototype.split(regex)`, the resulting array guarantees that matching groups are at odd indices. This allows replacing O(N*M) lookups (`highlightWords.some(...)`) with O(1) indexing (`index % 2 === 1`). Furthermore, wrapping such heavy computational components in `React.memo` and utilizing `useMemo` for regex and string splitting prevents unnecessary recalculations during unrelated parent state updates.
**Action:** Always leverage odd-index math for highlighted terms from regex splits to achieve O(1) identification. For text processing components, wrap the component in `React.memo` and memoize regex creation and splitting logic using `useMemo` to ensure stable references and avoid redundant computation on re-renders. Ensure hooks are placed correctly before early returns to obey the Rules of Hooks.
