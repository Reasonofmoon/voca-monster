## 2024-03-01 - [Optimize String Splitting React Component O(N) to O(1)]
**Learning:** When using `String.prototype.split` with a capturing group regex (e.g., `text.split(/(...)/)`), the resulting array alternates between unmatched and matched segments. The matched items are *always* located at odd indices. Searching the highlighted words array again during the `.map()` loop creates an O(N) operation per word segment, which scales poorly.
**Action:** Replace the `highlightWords.some(...)` checks inside the `parts.map()` render loop with a simple `index % 2 === 1` index check. This provides O(1) identification of matched elements and improves performance significantly. Also cache the regex construction using `React.useMemo` to prevent recalculations on parent state updates.
