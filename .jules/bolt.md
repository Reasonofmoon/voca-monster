## 2024-07-01 - [O(1) String Highlighting via Capturing Regex Split]
**Learning:** In React components like `AnalyzedContent` that highlight multiple specific words within a larger text block, using `String.prototype.split` with a capturing group regex guarantees that odd indices in the resulting array correspond exactly to the matches. This eliminates the need for expensive nested loops (e.g., `O(N * M) Array.some()` string comparisons).
**Action:** When refactoring or building text-highlighting components, construct a capturing regex for the target terms, use it to split the string, and identify highlighted segments directly via `index % 2 === 1`. Ensure existing escaping sequences within the regex construction are strictly preserved to avoid double-escaping errors (`SyntaxError: Invalid regular expression flags`).
