## 2024-03-24 - [Optimize Text Highlighting with O(1) checks and Memoization]
**Learning:** When using `String.prototype.split()` with a regular expression containing capturing groups, the resulting array interleaves the non-matched segments with the matched segments. Specifically, odd indices (1, 3, 5...) are always the captured matches. Using `.some()` inside `.map()` for every element in the split array leads to O(N*M) complexity (where N is text parts and M is highlighted words), especially expensive for large texts.
**Action:** Replace the expensive `.some()` check inside the map with a simple O(1) index check (`index % 2 === 1`). Furthermore, wrap the component with `React.memo` to prevent re-renders on unrelated parent state changes (like word selection), and use `useMemo` for regex compilation and splitting to avoid doing it on every render.
