## 2025-05-13 - [O(1) Array Highlighting with Capturing Regex]
**Learning:** When using `String.prototype.split` with a capturing group regex (e.g., `/(word1|word2)/`), the resulting array reliably places matches at odd indices. This guarantees an O(1) mathematical index check (`index % 2 === 1`) instead of performing an O(N) linear search (`array.some(...)`) on every iteration.
**Action:** When rendering split text chunks in React and determining which chunks to highlight or modify, rely on the odd index pattern instead of searching for the string again, reducing a potential O(N^2) complexity to O(N). Additionally, wrap the parent component in `React.memo` and the chunk splitting logic in `React.useMemo` to prevent deep recalculations when sibling states (like selected items) update.
