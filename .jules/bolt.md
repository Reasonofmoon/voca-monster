## 2024-04-26 - O(1) Lookup for Highlighted Text using Split Regex Capturing Groups
**Learning:** When using `String.prototype.split(regex)` in JavaScript where the `regex` contains a capturing group (e.g., `/(pattern)/`), the resulting array always interleaves the unmatched text with the matched capturing groups. This means that odd indices (`1, 3, 5...`) in the resulting array are guaranteed to be the exact matched substrings, while even indices are the surrounding text.
**Action:** Instead of iterating through the split array and performing an O(N) array lookup (`Array.some()`) against a list of target words for every segment to see if it should be highlighted, use the mathematical property of the split result: `if (index % 2 === 1)` guarantees an O(1) identification of the highlighted match. This significantly reduces the time complexity of text highlighting components during render.
