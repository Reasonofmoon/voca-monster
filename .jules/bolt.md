## 2024-06-18 - String.prototype.split with capturing regex groups enables O(1) identification
**Learning:** In `App.tsx`'s `AnalyzedContent` component, text highlighting was previously done by splitting the text with a capturing regex and then running an O(N*M) `.some` search on the highlighted words array for every single part. Because `String.prototype.split` with a capturing regex guarantees that odd indices in the resulting array correspond directly to the regex matches, we can identify highlighted words in O(1) time simply by checking if `index % 2 === 1`.
**Action:** When refactoring text highlighting or replacing logic in React components that use `String.prototype.split` with capturing regexes, always remember that odd indices are the matches. This eliminates the need for expensive nested array searches during rendering. Also, apply `React.useMemo` to the regex creation and splitting to avoid recalculating the split array on every re-render, especially since parent state changes (like selecting words) can trigger re-renders of this component.
