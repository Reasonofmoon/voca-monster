## 2024-03-11 - O(1) Lookup with String.prototype.split
**Learning:** When using `String.prototype.split(regex)` with a capturing group in the regex, the resulting array interleaves unmatched segments and matched groups. This guarantees that odd indices in the array will always be the matched substrings. This behavior allows replacing an `O(N)` lookup (`Array.prototype.some`) on every substring chunk with a simple `O(1)` index check (`index % 2 === 1`). Furthermore, utilizing React's `useMemo` correctly (placing it before any early returns) caches expensive string operations and regex constructions.
**Action:** Always prefer `useMemo` caching and index-based logic instead of repeated array lookups when building split-based highlighting components, specifically leveraging capturing group index rules.
