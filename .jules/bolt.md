## 2024-06-23 - Optimize AnalyzedContent String Splitting and Traversal
**Learning:** In `App.tsx`, the `AnalyzedContent` component dynamically highlighted words by doing an O(M) `.some()` check inside an O(N) `.map()` loop (where N is text parts and M is highlighted words). Because the text is split using a capturing regex string `split(regex)`, the matched capturing groups are guaranteed to fall exactly on odd indices of the resulting array. We can therefore replace the O(M) nested search entirely with an O(1) modulo index check (`index % 2 === 1`). Furthermore, the expensive regex creation was recalculating every render because the component wasn't memoized.
**Action:** When dynamically highlighting text split via a capturing regex, use `index % 2 === 1` to instantly identify matches instead of searching the highlighted words array again. Wrap components with `React.memo` and memoize the split operation using `useMemo` to prevent repetitive expensive string operations.
