## 2024-06-20 - O(1) Identification in Capturing Regex Splits
**Learning:** When using `String.prototype.split(regex)` with a capturing group in the regular expression, the resulting array interleaves the captured matches with the non-matched segments. Specifically, the captured matches are always placed at odd indices in the array. This allows for $O(1)$ identification of matched segments (`index % 2 === 1`) instead of performing an $O(N)$ array scan (`Array.prototype.some()`) against the list of original strings for every element in the split array.
**Action:** Whenever implementing inline text highlighting or processing that relies on `split` with a capturing regex, use the index modulo 2 trick to safely and efficiently identify matched segments instead of redundant string comparisons.
