## 2024-05-10 - O(1) Capturing Group Matches with String.split()
**Learning:** When using `String.prototype.split()` with a regular expression that contains a capturing group (e.g., `text.split(/(match_me)/)`), the resulting array is guaranteed to alternate between non-matches and capturing group matches. Specifically, matches always land at odd indices (1, 3, 5, etc.). This means we can replace O(N) lookup checks (`matches.some(...)` inside a `.map()`) with a simple O(1) index parity check (`index % 2 === 1`). This is particularly useful in React for highlighting words in text efficiently.
**Action:** When parsing strings to highlight dynamic matched words using regex capturing groups, use `index % 2 === 1` within the `.map` iteration to identify the highlighted pieces instead of searching an array for string equality.
