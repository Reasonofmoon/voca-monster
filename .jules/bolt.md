## 2024-05-23 - AnalyzedContent Component O(1) Mathematical Lookup Pattern
**Learning:** The `String.prototype.split()` function in JavaScript, when passed a regular expression containing a capturing group (e.g., `text.split(/(match)/)`), interleaves the matched portions into the resulting array at odd indices (1, 3, 5, etc.), while the non-matched portions occupy even indices (0, 2, 4, etc.). Previously, the `AnalyzedContent` component mapped over the split parts and performed an expensive `O(n)` array `.some()` check inside the loop to determine if the part was a highlight word, leading to `O(n*m)` complexity.
**Action:** When working with text-highlighting algorithms that use `.split()` with capturing regexes, replace expensive array lookups inside the mapping loop with an `O(1)` mathematical parity check (`const isHighlight = index % 2 === 1;`). This drastically improves string processing performance without sacrificing code readability.
