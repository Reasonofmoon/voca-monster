## 2024-06-28 - Optimizing React Memoization with Regex Capturing Groups
**Learning:** When using `String.prototype.split` with a regex containing a single capturing group, the resulting array perfectly alternates between non-matched text (even indices) and matched text (odd indices). This allows replacing a costly O(N) array lookup (`highlightWords.some(...)`) with a lightning-fast O(1) modulo check (`index % 2 === 1`). Additionally, `React.useMemo` must be placed before any early returns to avoid violating the Rules of Hooks, even if the memoized value isn't used in the early return case.
**Action:** Always inspect array splitting logic for implicit structures like alternating matches. When optimizing components with `React.useMemo` that involve conditional early returns, ensure the hook call is hoisted to the top level of the component body, handling empty/fallback cases internally within the hook callback.
