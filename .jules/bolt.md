## 2024-05-16 - O(1) Match Identification using Capturing Regex Split
**Learning:** When using `String.prototype.split` with a capturing regex group (e.g., `/(pattern)/`), the resulting array consistently interleaves non-matching text and matching text. Odd indices are guaranteed to be the exact matches. The previous implementation performed an O(N) `.some()` array scan on every fragment to check if it was a highlighted word, which was highly inefficient for large texts and many keywords.
**Action:** Replace `Array.prototype.some` lookups inside `.map` iterations over regex-split text with a simple O(1) modulo check (`index % 2 === 1`). This is fundamentally faster and less prone to edge cases with casing or punctuation. Also remember to memoize the regex creation and splitting operation using `React.useMemo` to prevent rebuilding on every render.
