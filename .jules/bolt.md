## 2025-03-01 - [O(1) Text Highlighting via Split Capturing Group Predictability]
**Learning:** In text highlighting components where `String.prototype.split(new RegExp('...', 'gi'))` is used to divide text into normal and highlighted chunks, the array returned guarantees that matches for capturing groups are placed at specific indices. Specifically, if a single capturing group is used, all matches are placed at odd indices in the resulting array. This predictable structure means we can replace O(N) lookup operations (e.g., `highlightWords.some(w => w === part)`) with a simple O(1) index check (`index % 2 === 1`). This is a critical pattern for any application highlighting numerous search terms or keywords in large bodies of text.
**Action:** Always check how `split()` is used in text parsing. If a capturing group is used for extracting matches, leverage the predictable array index structure (odd indices for single capturing groups) rather than re-evaluating each chunk against the array of search terms.
