## 2024-05-08 - [AnalyzedContent String Parsing Bottleneck]
**Learning:** [The React rendering loop inside `AnalyzedContent` historically recreated an expensive Regex instance, performed a `String.prototype.split()`, and ran an O(N) `Array.prototype.some()` string inclusion check nested inside a `.map()` loop for every highlighted text segment. This nested iteration scaled poorly with long texts and numerous vocabulary words.]
**Action:** [Use `React.useMemo` to cache regex construction and text splitting. Capitalize on `String.prototype.split(capturingRegex)` behavior, which places exact matches at odd indices, to replace the O(N) array search with an O(1) `index % 2 === 1` check. Apply `React.memo` to the component itself to prevent re-renders when parent states change.]
