## 2024-04-09 - O(1) String Highlighting via Regex Splitting Group Interleaving
**Learning:** In the `AnalyzedContent` component, `String.prototype.split(regex)` uses a top-level capturing group to preserve matched separators. This inherently structures the resulting array to strictly alternate between non-matches (even indices) and exact matches (odd indices). A previous $O(N \times M)$ operation (`.some` loop on the `highlightWords` array) was completely redundant.
**Action:** When evaluating React components that parse strings using splitting with capturing groups, immediately check if the index modulus (`index % 2 === 1`) can replace an expensive array scan. Implement this optimization alongside `React.useMemo` to cache the string generation and prevent component re-renders.
