## 2024-06-12 - React Component Optimization using String.split() Regex Capturing Groups
**Learning:** In the `AnalyzedContent` component within `App.tsx`, we were splitting strings using `String.prototype.split(regex)`. Because the regex contained a capturing group (`()`), JavaScript's split method interleaves the matched capturing groups into the resulting array. This means that odd-indexed items in the resulting array are exactly the matches.
We originally iterated over this array and did an O(N) lookup (`highlightWords.some()`) against the matched array to figure out which pieces of text to highlight. Because of how capturing groups in regex splits work, we can entirely skip the lookup and just check `index % 2 === 1` for O(1) identification of highlighted words.
**Action:** When working with text highlighting components, consider `String.prototype.split()` using capturing groups combined with `React.memo` and `React.useMemo` to eliminate unnecessary N^2 nested array lookups and heavy regex string processing on component re-renders.
