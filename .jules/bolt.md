## 2024-05-24 - [O(1) Identification of Regex Matches in React Mapping]
**Learning:** When using `String.prototype.split` with a capturing regex (e.g., `text.split(/(...)/)`), the matched strings are strictly guaranteed to fall on odd indices in the resulting array, and non-matched segments on even indices. This codebase used this technique for text highlighting but incorrectly performed an O(N) `.some` lookup on an array of words for every single mapped part, turning what should be an O(N) map operation into O(N*M).
**Action:** When mapping over split string fragments generated from capturing regexes in React, replace `O(N)` secondary searches (`.includes()` or `.some()`) with simple O(1) index parity checks (`index % 2 === 1`) to instantly and accurately identify matches.
